# Osmar Liera — Portfolio

Portafolio profesional bilingüe de Osmar Liera, Backend / Full-Stack Engineer. Presenta productos propios, experiencia profesional, stack técnico y versiones especializadas del CV.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
npm run preview
```

La compilación de producción se genera en `dist/`.

## Contenido principal

- `src/App.tsx`: contenido, traducciones y comportamiento de la interfaz.
- `src/styles.css`: dirección visual y diseño responsive.
- `public/images/`: capturas públicas de los productos.
- `public/cv/`: CV Full-Stack, Backend y Frontend.

Las capturas incluidas fueron seleccionadas para evitar publicar proyectos o datos internos. El trabajo para Shasa se presenta como contribución profesional realizada dentro de Nuts Marketing.
